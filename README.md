# 本地文件夹访问演示（File System Access API）

在网页中申请本地目录权限，浏览目录、预览文件、写入/新建/删除文件，并完整处理
权限被拒、浏览器不支持、非安全上下文、句柄持久化失败、权限失效、写入失败等异常。
不使用任何框架，仅使用原生 DOM / Blob / IndexedDB。

## 运行方式

File System Access API 要求**安全上下文**（HTTPS 或 `http://localhost`），
直接双击用 `file://` 打开会自动进入降级模式。建议本地起一个静态服务器：

```bash
# 任选其一，在项目根目录执行
python3 -m http.server 8080
npx serve .
```

然后访问 <http://localhost:8080/>。

浏览器要求：桌面版 Chrome / Edge（推荐最新版）。Firefox / Safari 目前不支持
`showDirectoryPicker`，页面会自动降级。

## 功能说明

- **申请目录访问权限**：点击顶部按钮，在用户手势内调用 `showDirectoryPicker({ mode: 'readwrite' })`
  并通过 Permissions 语义的 `requestPermission` 获取读写授权。
- **浏览目录 / 打开文件 / 预览**：面包屑导航、文件夹双击进入；文本文件内置编辑器，
  图片 / 视频 / 音频 / PDF 内嵌预览，二进制或超大文件显示信息卡。
- **写入 / 新建 / 删除**：`createWritable` 写入；可新建文件、文件夹；删除支持递归目录。
  支持 `Ctrl/⌘+S` 保存。
- **权限状态展示**：权限状态（已授权 / 待授权 / 被拒绝）、目录句柄名称、授权时间、运行模式。
- **权限失效重新授权**：句柄通过 IndexedDB 持久化，下次打开自动恢复（仅静默查询，不弹窗）；
  浏览器回收权限后显示「重新授权」，页面重新获得焦点/可见时也会静默复查。
- **写入失败重试**：权限被拒、配额不足或其它错误时弹窗，可「重试写入」（重新走授权）
  或「下载副本」保留修改；编辑器内容不会丢失。
- **降级模式**（覆盖基本操作）：
  - 不支持 API / 非安全上下文 / 授权被拒（可手动切换）时启用；
  - 用 `<input type=file>`（支持文件夹导入）读取文件；
  - 用 `Blob` + `a[download]` 完成写入/新建（保存即下载副本）；
  - 用 IndexedDB 虚拟文件系统支持目录浏览、新建、删除（降级删除只影响会话副本，不动磁盘原文件）。
- **句柄持久化失败降级**：IndexedDB 不可用或句柄结构化克隆失败（`DataCloneError`）时，
  本次会话仍可正常使用，并明确提示刷新后需重新授权。
- **用户未交互不崩**：页面加载只调用 `queryPermission`，绝不自动调用
  `requestPermission`/`showDirectoryPicker`（两者都必须在用户手势中）。

## 代码结构

```
index.html          页面结构
css/style.css       样式
js/app.js           主控：环境检测、权限流程、浏览/预览/增删改、重试、Toast/模态框
js/adapters.js      AccessAdapter（原生）与 FallbackAdapter（选择+下载+虚拟 FS）
js/storage.js       IndexedDB 封装（kv / vfs），失败时内存降级
```

## 异常分支对照

| 场景 | 行为 |
| --- | --- |
| 权限被拒 | 红色横幅 + 状态徽章；可重新授权或一键进入降级模式 |
| 浏览器不支持 | 警告横幅，自动降级为文件选择 + 下载 |
| 非安全上下文 | 错误横幅说明原因，自动降级 |
| 句柄持久化失败 | 会话内可用，提示刷新后需重新选择目录 |
| 权限失效 | 显示「重新授权」；焦点/可见性变化时静默复查 |
| 写入失败 | 弹窗可重试（重新申请权限）或下载副本 |
| 用户取消选择 | Toast 提示，不报错 |
| 未交互调用 | 仅静默查询权限，无弹窗、不抛错 |
